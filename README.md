# BLITZ Web App (React + Vite)

## Prerequisites
- Node.js 20+
- npm 10+

## Install
```bash
npm install
```

If PowerShell blocks `npm` scripts, use:
```bash
npm.cmd install
```

## Run (Real-Time Updates / HMR)
```bash
npm run dev
```

PowerShell alternative:
```bash
npm.cmd run dev
```

The app runs on:
- `http://localhost:5173`

Vite HMR is enabled, so saving files in `src/` updates the app instantly in the browser.

## Other Scripts
```bash
npm run build
npm run preview
npm run lint
```
